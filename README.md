# Laboratório de regressão

Este repositório versiona os materiais do laboratório por ano:

- `2025/lab-regressao-aula/`: materiais históricos;
- `2026/lab-regressao-aula/`: materiais vigentes em 2026, incluindo fontes e PDFs das aulas.

Os demais diretórios desta pasta de cursos não fazem parte deste repositório. Para preparar as aulas atuais, trabalhe diretamente em `2026/lab-regressao-aula/` na branch `main`.
